2. Какие данные собираются

Через форму заявки на сайте могут обрабатываться имя, номер телефона и комментарий пользователя о ситуации. Также могут обрабатываться технические данные, которые передаются браузером и сервисами аналитики.

3. Цель обработки

Данные используются для связи с пользователем, уточнения адреса и обстоятельств вызова, подготовки ответа на заявку и оказания услуги аварийного вскрытия замков.

4. Правовое основание и согласие

Отправляя форму, пользователь подтверждает согласие на обработку указанных данных для обработки заявки. Пользователь может не отправлять форму и связаться по телефону.

5. Аналитика

На сайте может использоваться Яндекс.Метрика для оценки посещаемости и улучшения работы страниц. Сервис может собирать обезличенные технические сведения о действиях пользователя на сайте.

6. Передача данных

Данные не публикуются в открытом доступе. Передача возможна только лицам, которые участвуют в обработке заявки, техническом обслуживании сайта или когда такая передача требуется по закону.

7. Срок хранения

Данные хранятся столько, сколько необходимо для обработки заявки и последующей связи по обращению, если иной срок не требуется по закону.

8. Права пользователя

Пользователь может запросить уточнение, удаление или ограничение обработки своих персональных данных, направив обращение на контактный email оператора.
